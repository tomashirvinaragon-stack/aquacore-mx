# Fotografías de productos AquaCore MX

La tienda busca automáticamente una fotografía WEBP para cada producto en esta carpeta.

Formato de nombre:
- Producto 1  -> 001.webp
- Producto 2  -> 002.webp
- ...
- Producto 91 -> 091.webp

Recomendación:
- Fondo blanco o transparente.
- Formato WEBP.
- Imagen cuadrada, ideal 1200 x 1200 px.
- Peso recomendado menor a 350 KB.
- Una sola fotografía principal por producto.

Si una fotografía todavía no existe, la tienda conserva automáticamente el gráfico de categoría actual como respaldo.

También se puede definir una ruta personalizada mediante la propiedad "image" dentro de data/products.json.
